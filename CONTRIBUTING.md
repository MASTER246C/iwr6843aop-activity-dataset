# Contributing and human validation

This project is just beginning. No dataset or review queue is released yet.
To volunteer, open a GitHub issue in this repository addressed to the maintainer.
Do not include personal recordings, participant details, consent forms or private
contact information in a public issue. Arrange an approved review workflow first.

Human validators may receive GitHub acknowledgment for accepted review work.
Choose an opt-in preferred display name or GitHub handle, or remain anonymous.
A public acknowledgment does not imply authorship, endorsement or rights to
participant data. No current volunteer contributions are claimed.

For each assigned review, record a review ID, recording/annotation version,
reviewer pseudonym, decision, time and reason. Preserve the original captured
annotation and any AI suggestion. Mark ambiguous boundaries/disagreements and
escalate unresolved cases rather than forcing a label. The final human decision
must be distinguishable from every automated proposal. Review access does not
authorize redistribution or public uploads.

See SCHEMA.md and RELEASE_CHECKLIST.md. Final contribution/data terms and access
arrangements must be established before any private recordings are shared.
