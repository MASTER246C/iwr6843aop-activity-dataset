# Before the first data release

- [ ] Confirm creator credit and adopt final dataset terms; include exact version.
- [ ] Review participant rights/consent for intended public and commercial reuse.
- [ ] Independently clear any optional video and remove unnecessary identifiers.
- [ ] Audit real export format; finalize schema, units and clock/coordinate conventions.
- [ ] Record firmware/CFG hashes and collection/calibration procedure.
- [ ] Preserve original labels and any AI proposals; complete human final review.
- [ ] Verify timing, dropped packets, exclusions, duplicates and class counts.
- [ ] Establish session/participant-held-out split and leakage checks.
- [ ] Generate checksummed file manifest and reconcile actual counts/durations.
- [ ] Update dataset card, changelog, citation and limitations from actual evidence.
- [ ] Explicitly authorize each approved capture publication; no automatic uploads.

No checked box or released sample is implied by this planning document.
